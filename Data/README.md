## Dataset Access

The dataset used in this project contains sensitive clinical information
collected from a rehabilitation hospital involving pediatric patients.

Due to privacy, ethical, and data-sharing restrictions, the raw dataset
cannot be publicly shared.

To ensure reproducibility and transparency:
- All preprocessing steps are documented in code
- Feature definitions and schema are described below
- Models can be run using synthetic or user-provided data following the same schema

If you are a researcher or reviewer and require access for academic purposes,
please contact me directly.
